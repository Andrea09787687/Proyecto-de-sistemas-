# Manual de relaciones

Deja aquí el manual de relaciones del modelo (PDF, Word, Excel o Markdown).
Si no tienes uno, copia `plantilla-relaciones.md`, renómbralo y llénalo.

El agente necesita, por cada relación:
- Tabla y columna de origen (lado "muchos", normalmente la tabla de hechos)
- Tabla y columna de destino (lado "uno", normalmente la dimensión)
- Cardinalidad (1:*, 1:1, *:*)
- Dirección del filtro (única / ambas)
- Si está activa o inactiva
